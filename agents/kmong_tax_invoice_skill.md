## 3. 표준 실행 워크플로우 (4단계 파이프라인)

```
[1단계: 주문 감지 및 보고] ➔ [2단계: 구매자 메시지 발송] ➔ [3단계: 세금계산서 신청 확인] ➔ [4단계: 신청 시 계산서 발행]
```

### 1단계: 신규 주문 감지 및 접수 보고
- 네이버 메일(`dnjsrns123@naver.com`)로 `[크몽] 신규 주문 #[주문번호] 접수 안내` 인입 시 즉시 감지.
- 주문 정보(주문번호, 상품명, 결제금액, 의뢰인 닉네임, 주문일시)를 요약 카드로 피클 채팅방에 즉시 전송.

### 2단계: 구매자 안내 메시지 자동 발송
- **상품 1: '인스타 공동구매 인플루언서 2127명+맘카페 리스트'**인 경우:
  1. 브라우저로 주문 상세 페이지(`https://kmong.com/order-detail/[주문번호]`) 접속 후 의뢰인 영역의 **[문의하기]** 클릭 (또는 메시지 센터 직접 이동).
  2. 대화창 하단 툴바에서 **[자주 쓰는 문구]** 버튼 클릭.
  3. 목록 첫 번째(1번) 항목인 **'리스트 구매 문구'** 클릭 ➔ 본문에 템플릿 문구 자동 삽입 확인.
  4. **[전송]** 버튼 클릭하여 구매자에게 발송 완결.
  5. 피클 채팅방에 "구매자([의뢰인])께 '리스트 구매 문구' 메시지 전송 완료" 보고.
- **상품 2: 대표 전자책('무자본X팔로워0명으로 월200만원 공동구매 중개 수익화' / gig #582625)**인 경우:
  1. 브라우저로 주문 상세 페이지(`https://kmong.com/order-detail/[주문번호]`) 접속 후 의뢰인 영역의 **[문의하기]** 클릭 (또는 메시지 센터 직접 이동).
  2. 대화창 하단 툴바에서 **[자주 쓰는 문구]** 버튼 클릭.
  3. 목록 두 번째(2번) 항목인 **'전자책 구매 문구'** 클릭 ➔ 본문에 템플릿 문구 자동 삽입 확인.
  4. **[전송]** 버튼 클릭하여 구매자에게 발송 완결.
  5. 피클 채팅방에 "구매자([의뢰인])께 '전자책 구매 문구' 메시지 전송 완료" 보고.

### 3단계: 세금계산서 신청 여부 점검
- 브라우저로 크몽 판매 관리(`https://kmong.com/seller/order-list?hasTaxRequest=true`) 접속.
- 해당 주문에 **[세금계산서 정보]** 버튼 또는 세금계산서 신청 표식이 있는지 확인.
- **세금계산서 신청이 없는 경우**:
  - 피클 채팅방에 "세금계산서 미신청 건 확인 (별도 발행 불필요)" 정리 보고 후 워크플로우 정상 종결.
- **세금계산서 신청이 있는 경우**:
  - 즉시 4단계(발행 파이프라인) 착수.

### 4단계: 세금계산서 사전 승인 및 홈택스 정식 발급 (신청 시)
1. **세무 정보 추출**:
   - 크몽의 [세금계산서 정보] 모달을 열어 구매자 상호, 대표자명, 사업자등록번호, 주소, 업태, 종목, 이메일 추출.
2. **사전 승인 요청**:
   - 피클 채팅방에 **세금계산서 발급 사전 승인 카드** 전송 (금액: 실결제금액 기준 공급가액/세액 분리 산정, 영수 체크).
3. **홈택스 작성 및 보류 등록**:
   - 지원진 님 카카오톡 간편인증 PUSH 발송 ➔ 홈택스 로그인 ➔ 사업자 '올쓰컴퍼니' 전환.
   - 전자(세금)계산서 건별발급 서식 작성 ➔ [발급보류]로 임시 저장.
4. **전자서명 및 발급 완결**:
   - 카카오뱅크 사업자 간편인증 전자서명 PUSH 발송 ➔ 지원진 님 앱 서명 완료.
   - 정식 발급 완료 후 국세청 24자리 승인번호 및 발급 증빙 화면 캡처 확보.
5. **크몽 전산 등록 및 보고**:
   - 크몽 판매 관리 [세금계산서 정보]에 국세청 승인번호 입력 및 [저장].
   - 피클 채팅방에 발급 완료 카드 전송 및 대시보드(`jeegong-web/data.json`) 갱신·배포.
