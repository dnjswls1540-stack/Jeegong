## 3. 대시보드 인터랙션 및 처리 규칙

1. **출근 & 업무 종료 2단계 워크플로우**:
   - `[✨ 출근 완료]` 클릭 시 5단계 프로그레스 애니메이션과 함께 5대 도구 실시간 동기화.
   - 출근 완료 즉시 버튼이 `[🌙 업무 종료]`로 변경되어 업무 진행 상태 유지.
   - 일과 후 `[🌙 업무 종료]` 클릭 시 `[🎉 퇴근 완료 ✓]` 상태로 전환되며 퇴근 축하 배너 노출.
2. **완료 항목 스마트 하단 이동**:
   - **투두메이트 할 일**: 완료 체크 시 취소선 적용과 함께 미완료 항목 아래(목록 맨 하단)로 자동 재정렬.
   - **에이전트 추천 우선순위**: 완료 체크 또는 제외 처리 시 목록 하단으로 자동 이동.
   - **중요 메일**: `[직접 완료]` 또는 `[제외]` 처리 시 조치 필요 메일 아래로 자동 정렬.
3. **중요 메일 3버튼 조치 시스템**:
   - **[직접 완료]**: 지원진 님이 이미 외부(웹/앱)에서 직접 처리한 메일 (완료 배지 부여 후 하단 이동).
   - **[제외]**: 불필요하거나 조치 대상이 아닌 메일 (브리핑에서 숨김/복구 가능).
   - **[답장 처리]**: 구름이가 사전 작성한 답장 초안 textarea가 열리며, 수정 후 `[승인 및 메일 발송 ✈️]` 시 자동 발송.
4. **구름이 웹 챗봇 (소통 & 멀티미디어 첨부)**:
   - 우측 하단 붉은색 `ㄹ` 구름이 프로필 버튼을 눌러 모바일/PC에서 실시간 업무 대화.
   - 대화창 확인 시 '1' 안읽음 배지 즉시 제거(읽음 동기화).
   - 클립(`📎`) 버튼으로 **사진, 이미지 시안, 동영상(mp4/mov), 엑셀 시트, PDF 문서**를 자유롭게 첨부 가능.
   - 첨부된 동영상은 대화창에서 즉시 재생되며, 구름이가 영상/시안/문서 내용을 인지해 맞춤형 피드백 제공.
   - 자연어 명령("세무사 통화 할 일에 추가해줘") 시 대시보드 할 일 목록에 실시간 반영.

## 4. 기능 추가 및 에이전트 수정 규칙 (유지보수 플로우)

1. **자연어 수정 접수**:
   - 지원진 님이 피클 앱 또는 웹 대시보드 챗봇에서 원하는 기능 추가나 변경 사항을 구름이에게 편하게 말씀하시면 구름이가 즉시 처리.
   - 예시: "출근 알람 시간 8시 40분으로 변경해줘", "특정 거래처 메일은 1순위 긴급으로 분류해줘", "대시보드에 신규 통계 지표 추가해줘".
2. **코드 및 스케줄드 액션 즉각 반영**:
   - 프론트엔드 코드(`jeegong-web/`) 수정 및 자동 빌드 배포.
   - 스케줄드 액션(`scheduled-actions/`) 스크립트(`check.sh`, `action.md`) 실시간 갱신.
   - 변경 결과를 스크린샷 및 카드와 함께 지원진 님께 완료 보고.

## 5. 엄격한 업무 규칙 (Operating Rules)

1. **원문 링크 필수 첨부**: 오늘 회의나 미팅에 필요한 사전 자료는 구글 드라이브 검색을 통해 찾고, 반드시 사용자가 바로 클릭해 열람할 수 있는 **원문 웹 링크(`webViewLink`)**와 함께 제공한다.
2. **사실과 추론의 명확한 구분**: 실제로 도구에서 확인한 객관적 사실(Fact)과 에이전트의 제안·의견(Proposal)을 명확하게 분리하여 서술한다.
3. **환각(Hallucination) 절대 금지**: 확인되지 않은 정보나 모르는 내용은 절대로 임의로 지어내지 않는다.
4. **간결성 극대화 및 토큰 낭비 방지**: 군더더기 없는 압축 서술을 유지하며 모바일 화면에서 가독성을 최우선으로 한다.
5. **노이즈 필터링**: 단순 광고, 마케팅 프로모션, 시스템 알림, 정기 뉴스레터는 배제한다.
